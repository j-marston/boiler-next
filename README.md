# About
Next.js 構築で使用するボイラーテンプレート

| stack | version |
| --- | --- |
| Next.js | 16.3.5 |
| React | 19.2.8 |
| Tailwind/postcss | 4 |
| oxlint | 1.85.0 |
| oxfmt | 0.70.0 |
| lefthook | 2.1.14 |
| Storybook | 10.6.0 |

## Getting Started

ローカル開発:

```bash
pnpm dev
```

URL: [http://localhost:3000](http://localhost:3000)

## CLI

| Command | Description |
| --- | --- |
| `pnpm dev` | 開発サーバー起動 |
| `pnpm build` | ビルド |
| `pnpm lint:fix` | リンターを実行して修正を適用 |
| `pnpm fmt` | フォーマッター |
| `pnpm fmt:fix` | フォーマッターを実行して修正を適用 |
| `pnpm storybook` | Storybookを起動 |
| `pnpm build-storybook` | Storybookをビルド |
